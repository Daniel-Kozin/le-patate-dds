# Le Patate DDS 🥔

A merge game with lecturers' faces, by Daniel Kozin, inspired by Guy Sokolik.

Play: https://daniel-kozin.github.io/le-patate-dds/

- `index.html`: the whole game
- `questions.json`: the quiz questions for Hard and Eviatar modes
- `we-are-kozin.mp3`: the theme song
- `firestore.rules`: security rules for the global leaderboard (paste them into Firebase → Firestore → Rules)
